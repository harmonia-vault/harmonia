# v0.1.0 验收清单

供真机人工验收逐项勾选。对应 [rewrite-plan.md](rewrite-plan.md) 第 8 节。

**准备：**
- 服务端：部署到自己的 Cloudflare 账号（见 [server/README.md](../server/README.md)），或在本机运行 `mise run dev-server`（验证码打印在终端里）。
- 手机：从 Releases 安装 APK。连接本机开发服务端时，Android 模拟器使用 `http://10.0.2.2:8787`；真机请使用部署后的 HTTPS 地址。
- 电脑：一台 Mac、一台 Linux（VPS 或虚拟机），用 `install.sh` 安装 CLI。

开发自检（不等于验收）已覆盖：三端单元测试、服务端 13 项、`e2e/run.sh` 覆盖 J1、J3–J9 的非界面部分、模拟器布局检查。

## B. 核心流程

- [ ] **J1 首次设置**：连接服务器 → 注册 → 输入邮件验证码 → 抄写恢复码并完整重输 → 进入“环境”页
- [ ] **J2 日常使用**：手机设置了锁屏时，冷启动先要求指纹或锁屏密码；退到后台超过 5 分钟再回来需要重新验证；没有锁屏的手机可在设置中开启 App PIN
- [ ] **J3 电脑接入**：`harmonia login <地址>` → 手机“设备 → 添加设备”扫码 → 选择环境与权限 → 批准 → 终端显示“已接入账号”
- [ ] **J3 核对码**：在“添加设备”中选择“输入核对码”，手输终端显示的 16 位码也能完成配对
- [ ] **J4 使用变量**：`harmonia env activate <环境>` + `harmonia shell install` 后新开终端 `echo $变量名` 有值；`harmonia exec -- printenv 变量名` 有值
- [ ] **J4 实时同步**：`harmonia service install` 后，在手机上修改变量，几秒内 `~/.harmonia/env.sh` 更新，新开终端拿到新值
- [ ] **J5 电脑写入**：读写权限的电脑 `harmonia var set <环境> <名> <值>` 后，手机上能看到；`harmonia import --env <环境>` 只上传勾选的变量
- [ ] **J6 本地覆盖与退出**：`harmonia override set` 只影响本机；云端删除该变量后覆盖失效；`harmonia logout` 后新开终端回到原来的值（如果你在 rc 文件里原本定义过同名变量）
- [ ] **J7 降权**：手机上把电脑改为“只读”，电脑 `harmonia var set` 提示只读
- [ ] **J7 撤销**：手机上移除电脑，在线电脑几秒内清除本机数据（`harmonia status` 显示未接入，`env.sh` 变空）；离线电脑联网后清除
- [ ] **J7 到期**：授权设置“1 天”，到期后电脑停用该环境（可把手机时间往后调验证服务端拒绝；电脑离线同样停用）
- [ ] **J8 恢复**：卸载 App 或换一台手机 → 登录 → “用恢复码恢复” → 强制更换恢复码（可同时设置新密码）→ 进入主页；旧恢复码再用会提示不对
- [ ] **J8 撤销旧手机**：恢复后在“设备”中移除旧手机
- [ ] **J9 第二台管理手机**：第二台手机登录 → “让另一台手机批准” → 第一台扫码、开启“作为管理手机”批准 → 第二台能看到并管理全部环境；之后可以移除它
- [ ] **J10 更新**：发布两个版本后，App“检查更新”能下载并安装新版本、数据保留；`harmonia update` 能升级并重启后台服务

## C. 生命周期

- [ ] 服务端 Sync fork 更新后，App 和 CLI 继续可用
- [ ] App 覆盖安装升级数据保留；卸载重装视为新设备
- [ ] `harmonia uninstall` 移除后台服务、rc 文件中的那几行、`~/.harmonia` 和程序本身
- [ ] 删除环境后，所有电脑同步移除其中的变量
- [ ] 重启电脑后后台服务自动运行（Linux 无需登录；macOS 登录后）
- [ ] 设置中修改登录密码、更换恢复码

## D. 异常场景（每项都应有明确提示）

- [ ] 地址错误 / 不是 Harmonia 服务 / 服务器连不上
- [ ] 密码错误；连续失败后提示稍后再试
- [ ] 配对超过 10 分钟过期；扫了别的二维码；在手机上拒绝配对
- [ ] 写入变量、批准设备、更换恢复码时断网
- [ ] 电脑离线时 `harmonia exec` 使用缓存并提示
- [ ] 两台设备同时修改同一变量，最终一致
- [ ] 删除一个电脑正在使用的环境
- [ ] 已撤销的电脑再次联网
- [ ] App 被系统杀掉后重新打开
- [ ] 恢复码输错
- [ ] rc 文件是符号链接（例如由 dotfiles 工具管理）时 `harmonia shell install` 给出手动添加说明
- [ ] 忘记密码：登录页“忘记密码”通过邮件验证码重设
- [ ] 重置账号：登录页“重置账号”删除数据后可用同一邮箱重新注册

## F. 新用户测试

在全新的 Cloudflare 账号、没装过 App 的手机、干净的 Linux 和 Mac 上，只看 README 完成：部署 → 使用 → 撤销 → 恢复 → 升级 → 卸载。任何卡住的地方都记为缺陷。
